# MG7
## Devlog

 in my TreeOfBirds script, array is used to store multiple bird game objects within the code. The vectors are used to determine how far apart the player is from the birds. This makes it so that the birds only pop up when the player is near. Using these key components make the interactions run smoothly and adds to the games graphic. Once the player meets the distance requirement, the code is set to "true" which makes the birds appear.
